# Star Codex v1.0.0

Local-first Android reader for five Thai manga/novel sites. Personal use —
no cloud, no server, no login, no ads. All data stays on your device.

## Install

1. Download `app-release.apk` below.
2. Open it and allow "install from unknown sources" if prompted.
3. Requires Android 7.0+ (API 24).

Note: if you previously installed a debug/test build, uninstall it first —
release builds are signed with a different key.

## What's inside (v1.0.0)

- **5 sources** — 4 manga sites (WordPress-Madara) + Nekopost (comics and
  Thai novels)
- **3 reading modes** — vertical webtoon, paged with left/right tap zones
  (RTL supported), and a novel reader with font/background settings
- **Automatic reading position** — reopen where you left off, auto-advance
  to the next chapter
- **Library** — add/remove, categories, cross-source merge for duplicate
  titles, new-chapter badges
- **Offline downloads** — pick chapter ranges with size estimates ahead of
  time; pages are recompressed to WebP (40–60% smaller) and the Offline
  tab only lists files that are actually on disk
- **Full settings** — Thai/English UI, themes, per-series reader mode,
  per-source enable/reorder, storage readout
- **Safety** — every network request goes through URL validation; nothing
  is ever sent off-device
